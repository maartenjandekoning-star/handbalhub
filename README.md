# HandbalNieuws Nederland 2.0

Upload de vijf bestanden uit deze map naar de hoofdmap van de GitHub-repository. Netlify publiceert daarna automatisch.

## Functies
- Alleen nieuws van de afgelopen zeven dagen op Home
- Dagoverzicht alleen op Home
- Foto’s, zoeken, filters en opslaan
- Livepagina met SHL TV
- Competitiepagina met officiële HandbalNL App Store-link, Handbal.nl en favoriete competitielink
- Voor jou op basis van eigen interesses
- Bronstatus en directe bronlinks

De automatische nieuwsfunctie gebruikt publieke feeds en externe leesroutes. Bij een tijdelijke storing blijft het laatst geladen nieuws lokaal beschikbaar.
