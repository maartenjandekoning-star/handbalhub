# HandbalHub 7.2 – kwaliteitsfilter

Nieuw in 7.2:

- WOS blijft als regionale bron, maar alleen berichten met expliciete handbalcontext worden toegelaten.
- Clubnamen alleen zijn niet genoeg, omdat WOS meerdere sporten volgt.
- Duidelijke voetbal/rugby-signalen worden geweerd tenzij er ook expliciet handbalcontext staat.
- Google Nieuws blijft als radar, maar alleen expliciet handbalrelevante resultaten worden opgenomen.
- Artikelen ouder dan 30 dagen verschijnen nergens meer.
- Ook oude cache-artikelen worden bij openen weggefilterd.
- Artikelen zonder betrouwbare datum worden niet getoond.
- 'Ouder nieuws' heet nu '8–30 dagen geleden'.

De rest van HandbalHub 7.1 is verder ongemoeid gelaten.
