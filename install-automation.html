HANDBALHUB

Automatische standen activeren

Geen API-sleutel en geen YAML kopiëren. De knop opent GitHub met de juiste map, bestandsnaam en workflow al ingevuld.

1. Tik op de oranje knop.
2. GitHub opent een nieuw bestand onder .github/workflows/.
3. Tik alleen op Commit changes.
4. De eerste update start automatisch met de gecorrigeerde workflow.
